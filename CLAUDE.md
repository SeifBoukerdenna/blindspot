# Blindspot — shared repository instructions

Read [AGENTS.md](AGENTS.md) first. It is the working agreement for every coding agent;
this file intentionally does not duplicate versions, machine state, test counts or feature gaps.

Start or resume with `make agent-context`, then read the relevant section of
[docs/agent-map.md](docs/agent-map.md), the target source and its callers/tests.
Use [docs/agent-workflow.md](docs/agent-workflow.md) for checks and local delivery,
and [docs/tasks/README.md](docs/tasks/README.md) for substantial task notes.

Current features and syntax: [docs/new-features.md](docs/new-features.md).
Build setup: [SETUP.md](SETUP.md). User-run publication: [docs/releasing.md](docs/releasing.md).

Historical reports and earlier handoffs are evidence for their recorded revision, not current
instructions. Never infer current installation state, indexing scope or missing functionality
from them. Source and fresh checks take precedence. Optional local hooks/rules do not replace
AGENTS.md, explicit user instructions or meaningful verification.
